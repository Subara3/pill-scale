# pill-scale（錠剤カウントはかり）

重さで錠剤の数を出す、自分用のはかり。薬の瓶を置きっぱなしにしておくと、1粒出したときに「○時○分 1粒減った」と記録する。

はんだ付けはしない。部品はねじ端子とGroveケーブルでつなぐ。

## 配線

```
[ロードセル] ─ねじ端子─ [Unit Weight-I2C] ─Groveケーブル─ [ATOMS3 Lite] ─USB-C─ [USB電源]
```

| ロードセルの線（uxcell 300g） | ユニットの端子 |
|---|---|
| 赤 | E+ |
| 黒 | E− |
| 青 | A+ |
| 白 | A− |

青と白（信号の線）を逆にしても、校正で向きごと覚えるので動く。

ロードセルは、線の側の端だけをスペーサーで台に留め、反対側の端を浮かせて、そこに皿を留める。浮かせた側が台や箱にふれていると、重さがそこに逃げて測れない。

## 書き込み

arduino-cli とボード定義 esp32:esp32（3.3.12で確認）。ボードは `esp32:esp32:m5stack_atoms3`。

```
copy firmware\pill_scale\secrets.example.h firmware\pill_scale\secrets.h   ← 家のWi-Fi（2.4GHz）を書く
arduino-cli compile --fqbn esp32:esp32:m5stack_atoms3 firmware\pill_scale
arduino-cli upload  --fqbn esp32:esp32:m5stack_atoms3 -p COM5 firmware\pill_scale
```

`secrets.h` は `.gitignore` で除外している。

## 使い方

1. スマホで http://pillscale.local/ を開く（開けなければ、シリアルに出るIPアドレス）
2. 皿を空にして「ゼロに合わせる」
3. 1円玉を何枚かのせ、のせたグラム数を入れて「校正」。のせる前と後の差が小さすぎるとき（300gのロードセルで1gあたり1,000カウント未満）は受け付けない
4. 錠剤を10粒のせて、名前を入れて「のせた数で覚える」。瓶から10粒出した差で測ったときは「1個を ○ gに直す」で数字を入れる
5. 薬の瓶を皿に置きっぱなしにする。瓶を持ち上げるなどで値がゆれ、また2秒落ち着いたら、ゆれる前の重さと比べて「○粒減った」と記録する

記録は「減った記録をCSVで取り出す」（/take.csv）で取り出せる。画面の「今日減った粒」は電源を抜くと0に戻る（CSVは残る）。

## つながり方と注意

- 家のWi-Fiにだけつなぐ。つながらないときも、本体が自分でWi-Fiを出すことはしない（30秒ごとにつなぎ直す）
- 画面は家のWi-Fiの中だけで開ける。家のWi-Fiにつないでいる人なら誰でも開けて、「ゼロに合わせる」なども押せる。来客にWi-Fiを貸すなら、ゲスト用のネットワークを使う
- Wi-Fi経由でのプログラムの書き換え（OTA）は入れていない。書き換えはUSBでつないだときだけ
- Wi-Fiのパスワードは本体の中に入る（ESP32のフラッシュは暗号化していない）

## 減った粒の見つけ方

- 値がゆれていないあいだは、「前の重さ」を今の重さに合わせ続ける（ゆっくりしたずれは数に入らない）
- ゆれたら、ゆれる前の重さを取っておく
- 2秒落ち着いたら、差を1粒の重さで割り、整数に近ければ（端数0.35以下）記録する

LEDの色: 赤＝ユニットが読めない、橙＝未校正、青＝ゆれている、緑＝安定。本体のボタンを押すとゼロに合わせる。

薬の数の判定は医療用途ではない（自分用の記録）。
